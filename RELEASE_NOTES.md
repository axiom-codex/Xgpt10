## Platform Features

- **One API Key** for all free & live AI models
- **7+ Providers**: Gemini, Groq, OpenRouter, Hugging Face, ChatGPT, Grok, Kimi
- **20+ Live Free Models**
- Gateway latency **< 15ms**
- Full **SSE Streaming** support
- Instant Developer Preview (no sign-in needed)
- Secure login with Google, GitHub, X, and Email
- Protected by Firebase Auth + Google Cloud
