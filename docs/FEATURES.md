# Xgpt10 Features

**Website:** [https://xgpt10.cloud.run](https://xgpt10.cloud.run)

Xgpt10 (API Hub) is a **Unified AI Key Platform** that gives you one API key to access multiple free and live AI models.

---

## Core Features

### 1. One API Key for All Models
- Generate a single unified API key (`ah_...`)
- Use the same key to call Gemini, Groq, OpenRouter, Hugging Face, ChatGPT, Grok, Kimi and more
- No need to manage multiple provider accounts and keys

### 2. OpenAI-Compatible API
- Endpoint works like OpenAI's Chat Completions API
- Easy to use with existing OpenAI SDKs and tools
- Supports streaming (SSE)

### 3. Live Streaming
- Real-time Server-Sent Events (SSE) streaming
- Low latency responses
- Gateway latency **< 15ms**

### 4. Multiple Free & Live Models
- **7+ Unified Providers**
- **20+ Live Free Models**
- Continuously updated model list

### 5. Developer Console
- Instant API key generation
- Live inference testing
- Easy provider/model routing
- Instant Developer Preview (no sign-in required)

### 6. Secure Authentication
- Sign in with **Google** (1-Click + Biometric Passkey)
- Sign in with **GitHub**
- Sign in with **Twitter (X)**
- Sign in with **Email**
- Protected by **Firebase Auth** + **Google Cloud Infrastructure**
